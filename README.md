# Partner landing pages

Two standalone landing pages (EN/RU) to link from the partner's website.

- `real-estate/` – resort real estate in Bali & Phuket
- `residency/` – second citizenship & residency programs
- `partner-links.html` – block to paste on the partner's site

Edit prices in the `PROJECTS` / `PROGRAMS` lists at the top of each page's script.
To send leads to a CRM, set `CONFIG.endpoint`; otherwise the form opens WhatsApp.
